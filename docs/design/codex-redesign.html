品牌黄使用铁律

  • 只出现在 3 处:Logo 方块、发送按钮(激活态)、流式输出 shimmer 扫光
  • 永不用作:hover 背景、激活项背景、边框、用户消息底色
  • 侧边栏激活态 = 中性灰 rgba(255,255,255,0.07),靠明度而非彩色
  • 浅色主题下文本级强调用 #B8860B 深金,#FFD700 仅存在于色块内
  • 成功 / 错误用低饱和 #7DBB6E / #E5716A,不与品牌黄抢焦点
